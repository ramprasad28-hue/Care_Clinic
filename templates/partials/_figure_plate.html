{% comment %} Photo-ready figure plate. Renders the original in-repo SVG illustration by default, or a self-hosted photograph when `image_url` is supplied — so an approved, licensed clinic image can drop into the same slot later with no markup change. The default illustration is a product-true scheduling scene — a week of availability with one slot confirmed, open slots and a dotted route from the booked time to the next opening. It is decorative (aria-hidden); the meaning is always carried by the real caption text. No clinical imagery, no invented claims, no external asset, no CDN (ADR-020). Params: caption — honest caption text shown under the plate (required) size — modifier key, e.g. "lg" for the homepage visual band (optional) image_url — a self-hosted image path; if set, an is rendered instead of the illustration (optional) image_alt — alt text for that image (optional; omitted/empty = decorative) width — intrinsic image width in px (recommended when image_url is set) height — intrinsic image height in px (recommended when image_url is set) loading — loading attribute for the image (defaults to "lazy") {% endcomment %}
